# Asset import inbox

Drop raw asset packs here (SFX, music, sprites, tiles, fonts, UI, etc.).

Agents install them into `client/Deathborn.Client/Content/` with proper categories and **without** vendor/pack names in destination paths. See [`AGENTS.md`](../AGENTS.md) → **Asset drop zone (`import/`)**.

This folder is a staging area only — do not treat paths under `import/` as runtime content.
